# QuickTask & SciCalc – Mini Web Apps

A collection of two handy, production‑ready single‑page web applications:

- **QuickTask** – a clean, responsive To‑Do List with persistent local storage.
- **SciCalc** – a fully‑featured scientific calculator with memory, history, and a dark theme.

Both apps are built with vanilla HTML, CSS, and JavaScript – no external frameworks or libraries (except FontAwesome for icons). They run entirely in the browser and are perfect for daily use, learning, or as a starter template for your own projects.

---

## 🚀 Features

### 📋 QuickTask – To‑Do List
- ➕ Add tasks via input field or **Enter** key.
- ✅ Mark tasks as complete (strikethrough + muted style).
- 🗑️ Delete individual tasks with a trash icon.
- 💾 Automatic data persistence using `localStorage` – tasks survive page refresh or browser restart.
- 🎯 Input validation: prevents adding empty tasks with visual feedback.
- 📊 Live task counter showing total and completed count.
- 🧘 Friendly empty state when no tasks exist.

### 🔬 SciCalc – Scientific Calculator
- ➕ Basic arithmetic: addition, subtraction, multiplication, division.
- 📐 Scientific functions: sin, cos, tan, log, ln, √, x², x³, xⁿ, factorial, %, ±.
- 🧮 Constants: π, e, EXP (scientific notation).
- 🧠 Memory functions: MC, MR, M+, M− with indicator.
- 📜 Calculation history panel (toggleable) – stores up to 100 entries.
- ⌨️ Full keyboard support: numbers, operators, Enter, Backspace, Escape.
- 🌙 Dark theme with a modern, polished UI.
- 📱 Responsive design works on desktop, tablet, and mobile.

---

## 🛠️ Tech Stack

- **HTML5** – semantic markup.
- **CSS3** – custom properties, Flexbox/Grid, animations, responsive media queries.
- **Vanilla JavaScript (ES6+)** – all logic, DOM manipulation, and event handling.
- **FontAwesome** – icon library (loaded via CDN).
- **localStorage** – for persistent task data (QuickTask only).

No build tools, no dependencies – just open the HTML files and go.
